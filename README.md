# Distance Between Two Points Calculator

## Description

This program is used to calculate the distance between two points (x1, y1) and (x2, y2) using input values and a math library.

## How to Run

1. Open the program file in VS Code, ChatGBD, or Google Collab.

2. Run the program.

3. Enter the values for x1, y1, x2, and y2.

4. Check the result displayed on the screen.

## Input Needed

- x1

- y1

- x2

- y2

## Sample Output

Enter x1: 3

Enter y1: 7

Enter x2: 9

Enter y2: 10

The distance between the two points is: 7.07
